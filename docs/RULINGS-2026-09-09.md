Three rulings from the owner, resolving the open questions from the independent

## R1 — Spec fingerprint: the LF hash is canonical (Finding #2)

Three spec files (`spec/schemas/signature.schema.json`,
`spec/skeleton/canonical-humanoid-v1.json`, `spec/skeleton/core.hands.v1.json`)
were embedded in the shipped fixtures with CRLF, while `.gitattributes`
(`* text=auto eol=lf`) checks them out LF. So a fixture's embedded
`spec_sha256` (`3984a555…`) and a fresh clone's `spec/` fingerprint
(`5f43e398…`) disagree.

**Ruling:** the **LF-checkout hash is canonical**:

```
canonical spec_sha256 = 5f43e3980a6c111e840bf99a381719f404f00911031d9df3635ccc935904ed1d   (LF)
historical shipped     = 3984a5550b8a4be95501c37544d36b90ac2f3834bdddf8007597a41405450ebd   (CRLF)
```

- The fixtures shipped to date (golden `crate-v1`, and the CC0 fixtures built on
  a `core.autocrlf=true` host) embed the **historical CRLF** snapshot and
  declare `3984a555…` in their manifests. This is documented as the historical
  shipped value, not a defect; those fixtures remain internally consistent
  (manifest hash = embedded spec hash) and every gate still passes on a plain
  run. `fixtures/fixtures.json` keeps `3984a555…` because it must match the
  actual embedded bytes for fixture-pinning to work.
- The **canonical repository spec fingerprint is `5f43e398…`** (the spec tree as
  checked out under the repo's own `.gitattributes`). The paper's
  externally-replicable spec-fingerprint claim is scoped to this LF value.
- Accepted trade-off (this is option (c) of the three Yuvraj offered): no
  fixture rebuild, no `.gitattributes` carve-out; the divergence is ruled
  historical and documented. Fixtures regenerated on a host with an LF checkout
  will naturally carry the canonical `5f43e398…`.

## R2 — The CUB gate is author-lab-only (Finding #4)

The Stage 5 CUB gate (`<lab>\CUB\crates\cub-werk`) cannot be replicated externally:
CUB is a private repository and its `<lab-ci-host>` runner is not publicly reachable.

**Ruling:** the CUB gate is **scoped author-lab-only** and is named as such in
the paper's Threats to Validity — it is an author-lab confirmation that the
universal core round-trips through a real game engine, not an externally
reproducible claim. The publicly reproducible engine-adapter evidence is the
Blender and Unreal roundtrip gates on the public fixtures.

## R3 — Gate 9 image determinism ships CC0 (Finding #3)

`tests/run_gate_9.py` re-runs `fixtures/build_image_fixture.py`, whose inputs
live in the private `<lab>\SFNovels` tree at a frozen date — so the builder-
determinism clause cannot run for an outsider.

**Ruling:** the publicly reproducible image arm is the **CC0** path:
`fixtures/build_image_cc0.py` → `image-cc0-v1.werk`, verified by
`tests/run_gate_cc0_image.py` (which now includes a builder-determinism clause).
`run_gate_9.py` keeps the private `ista-varun-v1` fixture as its author-lab arm,
but its private-input clauses now **SKIP** (not FAIL) when the private tree is
absent, and point to the CC0 gate as the public determinism proof.
