Files kept here (the geometry only, so the source is self-contained and small):
  wooden_crate_01_2k.gltf  — glTF 2.0 JSON. Three meshes (lid, body, latch),
                             one primitive each, attributes POSITION / NORMAL /
                             TEXCOORD_0, plus triangle indices. 4686 vertices,
                             6576 triangles across the three primitives.
  wooden_crate_01.bin      — the 189408-byte mesh buffer the .gltf references.

Deliberately NOT kept here: the three 2K texture JPEGs (diff / nor_gl / arm)
that the .gltf's image URIs point at. The werk fixtures do NOT use them: their
core.tex payloads are procedural PNGs generated deterministically in stdlib
Python (fixtures/build_crate_tex.py's map generators), so the whole build stays
byte-reproducible with no large binary blobs vendored. Download the originals
from the Poly Haven page above if you want the photographic maps.

This directory is the INPUT to fixtures/build_crate_cc0.py, which packages the
mesh into geometry/source.glb (verbatim) and geometry/game.glb (merged into one
conformant single-primitive mesh) inside the .werk fixtures.
